- (decision) AD-1 Paradigm = phased pipeline + mode router. Binds: whole spine. Prevents: UI logic scattered across steps; incompatible phase ordering; uninstall/install flows interleaving.
- (decision) AD-2 Runtime split = hybrid: batch orchestrates the pipeline + console UI; PowerShell owns all network/JSON/version-math. Prevents: version-math in pure batch; all-PowerShell losing simple cmd flow.
- (decision) AD-3 Single-file rule: shipped artifact is one self-contained .bat; all helpers (PS blocks, UI, manifest) inlined; no sidecar scripts. Prevents: broken distribution promise; fragmented artifact.
- (decision) AD-4 No-admin per-user gate: all mutations confined to %LOCALAPPDATA%, HKCU, user PATH; zero HKLM/%ProgramFiles% writes; zero UAC prompts. Git via MinGit, Node via ZIP, Python Include_launcher=0, VSCode User Setup. Prevents: Git installer elevating on admin accounts; admin-dependent installs.
- (decision) AD-5 Manifest is the source of truth for uninstall: uninstall removes only items recorded in %LOCALAPPDATA%\AITools\manifest.txt, plus autostart entries the tool created. Prevents: uninstall overreach touching user-installed apps.
- (decision) AD-6 Per-item decision model: each stack item's version check returns exactly one of INSTALL/SKIP/UPDATE + a normalized version string; never downgrade. Prevents: ambiguous states; downgrades; wrong 'not installed' verdicts (Store-stub, portable node).
- (decision) AD-7 Official sources only: every download from official domains (git-scm.com/git-for-windows GitHub, nodejs.org, python.org, update.code.visualstudio.com, npm registry); self-update only from giakhanhquoc141-rgb/AI_AGENT_INSTALL GitHub releases. Prevents: third-party mirrors; supply-chain drift.
- (decision) AD-8 Secrets never touch the tool: tool never reads/writes/stores/transmits API keys; keys entered by user in 9Router dashboard; manifest/log carry no key material. Prevents: key leakage into artifacts or network.
- (decision) AD-9 Step contract: every pipeline step exits 0 on success / nonzero on failure, appends one log line (step, ok/fail, version, path, timestamp), and on failure shows a Vietnamese user-level message (what + suggested next action), never a raw error code. Prevents: inconsistent error UX; raw codes shown to non-technical users.
- (decision) AD-10 PATH discipline: user PATH mutations via reg add HKCU\Environment (never setx — truncates >1024 chars); refresh PATH in-session after each PATH-mutating step before the next dependent step; read back from registry, not the stale console env. Prevents: PATH truncation; 'console restart required' mid-run.
- (decision) AD-11 UTF-8 + Vietnamese: console runs chcp 65001; all user-facing strings Vietnamese, no technical jargon, no English user strings; version check: 9Router/OpenClaw dashboards show at localhost ports only. Prevents: mojibake on Win10/11; accidental English leaking to end users.
- (decision) AD-12 Idempotency: re-running is safe; never reinstall over an existing install; never duplicate my-combo or autostart entries; plan phase re-derives decisions each run. Prevents: double-combo; reinstall loops; autostart duplicates.
